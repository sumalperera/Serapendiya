Implemented:

- `append_group` prepares multiple contiguous batches before any write.
- The group performs one segment write, one segment sync, one checkpoint, and
  one checkpoint durability sequence.
- All group offsets become visible after segment sync and durable only after
  checkpoint completion.
- Group failure remains terminal and preserves the existing safety ordering.
- Test instrumentation proves three batches use one segment sync and one
  checkpoint sync.

This is a synchronous bounded group API. No background queue, throughput target,
or production performance claim is made.
